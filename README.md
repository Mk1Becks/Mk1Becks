## 🧭 Wohin die Reise geht

Ein Data Scientist macht mehr, als Zahlen auszuwerten. Das ist der Weg, den ich gehen will:

1. **Data Cleaning & Preparation:** Rohdaten sauber machen, bevor sie etwas aussagen können
2. **Exploratory Data Analysis (EDA):** Muster, Ausreißer und Zusammenhänge finden
3. **Statistics:** Ergebnisse belastbar machen, statt nur Bauchgefühl zu liefern
4. **Machine Learning:** Modelle bauen, die Vorhersagen treffen
5. **Visualization & Storytelling:** Ergebnisse so zeigen, dass jeder sie versteht, auch ohne Datenbrille
6. **Business Impact:** aus Analysen konkrete Empfehlungen machen, die ein Unternehmen weiterbringen
